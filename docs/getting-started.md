# Getting Started with Premier League Oracle

Welcome to Premier League Oracle, your data-driven football prediction platform! This guide will help you get started with making AI-powered Premier League predictions using live API data.

## Quick Setup

### 1. First Time Setup

When you first open Premier League Oracle, you'll be greeted with a setup wizard that will guide you through:

- **Welcome Screen**: Introduction to the platform's features
- **Privacy Information**: How we protect your data (spoiler: we don't collect any!)
- **API Configuration**: Setting up your Football-Data.org API key
- **Ready to Go**: Start making predictions!

### 2. Get Your API Key

To use live Premier League data, you'll need a free API key from Football-Data.org:

1. Visit [Football-Data.org Registration](https://www.football-data.org/client/register)
2. Sign up for a free account
3. Verify your email address
4. Copy your API key from the dashboard
5. Paste it into the Premier League Oracle setup wizard

**Free Tier Includes:**
- 10 requests per minute
- Access to Premier League data
- Live match information
- Team statistics

### 3. Your First Prediction

Once setup is complete:

1. **Dashboard**: View the latest Premier League insights
2. **AI Assistant**: Ask questions about teams and matches
3. **Predictions**: Get AI-powered match predictions
4. **Live Data**: All information comes directly from official sources

## Privacy & Security

Premier League Oracle is designed with privacy-first principles:

- **Local Storage Only**: Your API key never leaves your browser
- **No Data Collection**: We don't track your usage or personal data
- **Direct API Calls**: Data comes straight from Football-Data.org
- **No Account Required**: Use anonymously
