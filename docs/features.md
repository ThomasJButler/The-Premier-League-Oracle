# Features Guide

Premier League Oracle is packed with advanced features for football prediction and analysis. This guide covers everything you need to know.

Your central hub for Premier League insights:

### Quick Stats Overview
- **Current league table** with live positions
- **Upcoming matches** for the next gameweek
- **Recent results** with key statistics
- **Top performers** in various metrics

### Smart Insights
- **Form trends** for all teams
- **Goal scoring patterns** over time
- **Defensive statistics** and clean sheet records
- **Home vs Away performance** breakdowns

### Visual Analytics
- **Interactive charts** showing team progression
- **Performance indicators** with colour coding
- **Trend analysis** for key metrics
- **Historical comparisons** across seasons

## ⚽ Predictions

Advanced AI-powered match predictions:

### Multiple Models
- **ELO Rating System**: Dynamic team strength calculations
- **Poisson Distribution**: Statistical goal prediction models
- **Expected Goals (xG)**: Shot quality and conversion analysis
- **Form-based Models**: Recent performance weighting

### Prediction Details
- **Match outcome** (Home/Draw/Away) with confidence scores
- **Exact score predictions** with probability distributions
- **Goal totals** (Over/Under markets)
- **Both teams to score** probability

### Historical Performance
- **Model accuracy tracking** across all predictions
- **Performance metrics** for different prediction types
- **Confidence calibration** showing when models are most reliable
- **Learning improvements** over time
